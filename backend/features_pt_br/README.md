# Cenários de negócio em português

Tradução dos arquivos `.feature` de `../features/` para leitura das partes interessadas.

**Estes arquivos são documentação: o behave não os executa.** A suíte (`behave.ini`,
`paths = features`) roda apenas a versão em inglês, que é a especificação executável.
Ao alterar um cenário em inglês, atualize a tradução correspondente aqui.

Os valores monetários seguem o formato brasileiro (R$ 440.000,00); os números são os
mesmos da versão em inglês.
